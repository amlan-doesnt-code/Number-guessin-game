# Number Guessing Game in C

My first C programming project!

A simple command-line game where the computer generates a random number between 1 and 100, and the player tries to guess it within three attempts.

## Features
- Random number generation
- Three attempts per game
- Hints for guesses that are too high or too low
- Win/loss messages

## Concepts Practiced
- Variables and data types
- `if-else` statements
- `for` loops
- Random number generation using `rand()` and `srand()`
- Basic input/output
- Using a flag to track the game result

## How to Run

Compile using GCC:

```bash
gcc guessing_game.c -o guessing_game
```

Run on Linux:

```bash
./guessing_game
```

On Windows, run:

```bash
guessing_game.exe
```
